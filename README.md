 # Data Search

A lightweight search tool built with vanilla JavaScript, HTML, and CSS. It filters through a dataset in real time based on user input and returns matching results, with clear feedback when no match is found.

## Live Demo

Try it here: [data-search-rust.vercel.app](https://data-search-rust.vercel.app/)

## Features

- **Live search** — Filters the data as you type.
- **Prefix matching** — Returns entries that begin with your input, powered by JavaScript's `startsWith()` method.
- **Error handling** — Displays a clear error message when the input doesn't match any data.

## Tech Stack

| Technology | Purpose |
| --- | --- |
| JavaScript | Search and filtering logic |
| HTML | Structure and layout |
| CSS | Styling and presentation |

## Getting Started

This is a static web project and requires no build tools or dependencies.

1. Clone the repository:
   ```bash
   git clone https://github.com/karan-raghav-27/DATA-SEARCH.git
   ```
2. Navigate into the project directory:
   ```bash
   cd DATA-SEARCH
   ```
3. Open `index.html` in your browser to start searching.

## How to Use

1. Type a query into the search box.
2. Matching results appear instantly as you type.
3. If nothing matches, an error message is shown.
